# Triage labels

The skills use five canonical triage roles. This file maps those roles to the labels in this repository.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | The reporter must provide more information. |
| `ready-for-agent` | `ready-for-agent` | The issue is specified and ready for an agent. |
| `ready-for-human` | `ready-for-human` | The issue needs human implementation. |
| `wontfix` | `wontfix` | The issue will not be addressed. |

When a skill mentions a role, apply the corresponding GitHub label.
