# Dashboard claims and queues

The owner overview separates estimated, Test Mode, mock, and simulated amounts with one ClaimTag per figure. Money is displayed as ₹INR after converting persisted paise values to rupees. Revenue at Risk uses persisted payment-source evidence: it shows MOCK or TEST MODE only when every contributing open case has that known source, and otherwise has no source tag. A mock reply may show its persisted Outcome, recovered amount, and MOCK source in Mock Inbox; it is not Test Mode evidence. The operations queue prioritizes owner escalations, aged PaymentExceptions, eligible cases by expected net value, and investigated cases by age. It shows work state and safety limits rather than aggregate recovery pressure.
